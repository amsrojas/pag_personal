# Página personal · Andrés M. Salazar

Esta versión conserva la portada y las exploraciones de v7 e incorpora la página
**Matemáticas para las Artes**.

## Abrir en VS Code

1. Abrir esta carpeta en Visual Studio Code.
2. Ejecutar `index.html` con Live Server.
3. Desplegar «Cursos» y pulsar «Matemáticas para las Artes».
4. Revisar los dos talleres en la sección «Talleres».

## Nuevos archivos

- `cursos/matematicas-artes.html`
- `cursos/archivos/taller-fundamentos-matematicos.pdf`
- `cursos/archivos/taller-razones-proporciones.pdf`

## Cambios en archivos compartidos

- `index.html`: enlace al nuevo curso.
- `css/estilos.css`: estilos reutilizables para los contenidos y datos de cursos.

La información del curso se basa en el syllabus suministrado (300MEA013,
2 créditos, modalidad presencial y seis grupos temáticos). Las actividades en
PDF se incorporan sin modificar su contenido.

**Nota:** El syllabus facilitado contiene una tabla de evaluación con porcentajes
que suman 103 % y referencias a CA7 aunque se enumeran CA1–CA6. Por ese
motivo la página no reproduce esos porcentajes ni publica el syllabus como
documento definitivo. Conviene corregir o confirmar esos puntos antes de
publicarlo.
